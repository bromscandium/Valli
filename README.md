# Valli 🌱

**Valli** is a smart farming and project management web platform designed to help farmers and agribusinesses monitor crop conditions and manage agricultural allProjectData efficiently.

## 🚀 Tech Stack

- **React**
- **React Router DOM** – client-side routing
- **Poppins** – main UI font
- **Custom SASS** – for styling
- **React Query** – for data fetching and caching
- **Backend** – API-ready (Node.js / Python / Express)

## 📦 Project Structure

```
/src

 index.html
```

## 🛠️ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/bromscandium/valli.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## ✨ Features

- Modular navigation (React Router)

- Mobile-friendly UI
